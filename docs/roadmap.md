# Roadmap

These are development priorities, not completed capabilities or delivery dates.

## 1. Finish native product verification

Observe a complete local coding interaction with linked tool records and an automatically produced investigation. Include a successful file-read control, an observable failure and an inconclusive case. Finish K2 read/write smoke checks in a disposable directory and compare it with Qwen only under a stated, matched protocol.

## 2. Add explicit task-level evidence

Define narrow, user-authorized task requirements and connect executable assertions or required-artifact checks to the recorded run. Keep technical execution status separate from task correctness. Design opt-in local evidence capture before retaining private code or outputs.

## 3. Make investigations more discriminating

Introduce bounded evidence collection only where it can distinguish specific competing explanations. Preserve abstention when evidence is insufficient. Record the work and permissions required for a probe; a logical evidence disclosure is not automatically a physical execution-cost saving.

## 4. Evaluate independently

Obtain independent review of reference contracts and test on cases not used to design the rules. Compare against strong deterministic and abstaining baselines. Report supported findings, mistakes, coverage, unresolved cases and actual probe costs without treating repeated trials as independent tasks.

## 5. Broaden integration after the core is verified

Consider additional agent frameworks and execution environments through explicit interfaces. Cross-agent support, autonomous recovery and model training require their own implementation and evidence; they are not implied by the current dashboard.

## Public repository maintenance

Add rights-cleared, sanitized screenshots of the existing interface when available. Keep a dated status summary and publish independently redistributable components only after reviewing their source ownership and tests. Use the [manual update workflow](public-updates.md); no automatic mirroring is planned.
