# Screenshots and visual assets

The application already has a retro CRT terminal identity: dark surfaces, green accents, a distinctive avatar, monospaced typography and recorded telemetry charts. Preserve that interface when making captures. This repository does not ship a redesign.

The architecture diagram is original explanatory material. It is not an application screenshot. Existing screenshot originals and the avatar file are withheld pending privacy review and redistribution clearance.

## Before adding a capture

- Confirm rights to every visible asset and any attribution that must accompany it. If uncertain, withhold the affected material.
- Capture the actual application. Do not fabricate model responses, tool events, charts or benchmark numbers.
- Remove browser chrome, account pictures, personal details, internal addresses, local paths, session/attempt identifiers, credentials and private content from the deliverable itself. Hiding a region in Markdown does not remove it from the downloadable image.
- Verify that the saved image contains no sensitive metadata or hidden full-window original.
- Keep the interface readable and visually unchanged. Do not replace the avatar, restyle components or generate a synthetic version of the dashboard.
- Add a caption with the date, whether the run was controlled, what is observed and what the image cannot establish. A still image alone cannot demonstrate automatic investigation timing.

Only add a screenshots directory when a cleared capture is ready. Do not commit placeholders or an unsanitized source image alongside a sanitized version.
